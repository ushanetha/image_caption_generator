# Image Caption Generator

## Problem Statement
Build an application that accepts images and generates descriptive captions using an image-captioning model or API, with storage and export of results.

## Tech Stack
- Python
- OpenCV
- Pillow
- Deep Learning Model/API
- NumPy
- File Handling

## Installation

```bash
python -m venv venv
```

### Windows
```bash
venv\Scripts\activate
```

Install dependencies:
```bash
pip install -r requirements.txt
```

Run:
```bash
streamlit run app.py
```

## Features
- Upload JPG, JPEG and PNG images
- AI-powered caption generation
- Image metadata extraction
- JSON result storage
- Caption history
- TXT export
- CSV export
